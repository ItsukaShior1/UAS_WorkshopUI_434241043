1.1 Paragraf Pengantar

Perkembangan teknologi informasi yang semakin pesat telah membawa perubahan signifikan dalam berbagai aspek kehidupan, termasuk dalam dunia bisnis. UMKM (Usaha Mikro, Kecil, dan Menengah) merupakan salah satu sektor yang sangat terdampak oleh perkembangan teknologi ini. Banyak pelaku UMKM yang mulai beralih dari sistem pencatatan manual menuju sistem digital untuk meningkatkan efisiensi dan akurasi dalam pengelolaan bisnis mereka. Namun demikian, tidak sedikit pula pelaku UMKM yang masih menghadapi kendala, seperti keterbatasan pengetahuan teknologi, biaya yang tinggi untuk perangkat lunak berbayar, serta tidak tersedianya fitur yang sesuai dengan kebutuhan spesifik bisnis mereka.

Bookify merupakan sebuah platform berbasis web yang dikembangkan untuk menjawab permasalahan tersebut. Bookify hadir sebagai solusi all-in-one bagi pelaku UMKM dalam mengelola pembukuan, inventori, laporan keuangan, serta komunitas bisnis dalam satu aplikasi terpadu. Bookify juga menyediakan fitur berlangganan paket, sehingga pengguna dapat memilih layanan yang sesuai dengan skala dan kebutuhan bisnisnya. Pada laporan ini, Bookify akan dibahas secara komprehensif, meliputi deskripsi topik, user story, use case, hingga use case specification sebagai dasar analisis kebutuhan sistem.


1.2 Deskripsi Topik

Bookify adalah aplikasi berbasis web yang ditujukan untuk membantu pelaku UMKM dalam mengelola operasional bisnis harian secara digital. Aplikasi ini dibangun menggunakan framework Laravel 13 dengan basis data MySQL, dan dirancang agar dapat diakses melalui browser desktop maupun mobile dengan tampilan yang responsif.

Secara garis besar, Bookify menyediakan dua jenis paket langganan utama, yaitu:

1. Paket Bookify App
   Paket dasar yang mencakup fitur pembukuan (pemasukan dan pengeluaran), manajemen stok atau inventori produk, laporan keuangan yang dapat di-export ke PDF, serta dashboard ringkasan bisnis.

2. Paket Bookify Marketplace
   Paket lanjutan yang mencakup seluruh fitur pada Paket Bookify App, ditambah dengan fitur integrasi marketplace seperti terhubung ke toko online, sinkronisasi produk, dan kelola pesanan dari berbagai marketplace dalam satu dasbor.

Kedua paket tersebut tersedia dalam dua periode penagihan, yaitu bulanan dan tahunan, sehingga pengguna dapat memilih sesuai kebutuhan. Pengguna yang sudah berlangganan Paket Bookify App akan secara otomatis mendapatkan diskon khusus ketika melakukan upgrade ke Paket Bookify Marketplace, sebagai bentuk apresiasi atas loyalitas pengguna.

Scope proyek Bookify mencakup:

a. Modul Autentikasi
   Sistem login dan logout, dengan perbedaan hak akses antara pengguna biasa (user) dan administrator (admin).

b. Modul Pembukuan
   Pencatatan transaksi pemasukan dan pengeluaran, kategori transaksi, unggah foto bukti transaksi, dan pencarian transaksi berdasarkan kata kunci, tipe, maupun kategori.

c. Modul Stok atau Inventori
   Pengelolaan daftar produk, pencatatan stok saat ini, stok minimum, harga jual, gambar produk, serta status stok (Aman, Rendah, Kritis). Termasuk riwayat transaksi per produk.

d. Modul Laporan
   Pembuatan laporan keuangan sederhana dalam bentuk tabel dan grafik, serta fitur export laporan ke PDF.

e. Modul Komunitas
   Forum diskusi antar pengguna Bookify untuk saling berbagi tips, bertanya, dan memberikan like pada postingan.

f. Modul Insight
   Halaman ringkasan performa bisnis pengguna dalam bentuk grafik dan statistik.

g. Modul Berlangganan
   Pemilihan paket langganan (App atau Marketplace, bulanan atau tahunan), proses checkout, integrasi pembayaran QRIS, serta pencatatan riwayat pembayaran. Tersedia fitur upgrade dengan diskon otomatis dan pembatalan langganan.

h. Modul Keranjang
   Pengguna dapat menambahkan beberapa item sebelum melakukan checkout, dengan ringkasan belanja otomatis.

i. Modul Marketplace Integration
   Pengelolaan koneksi ke marketplace eksternal (seperti Shopee, Tokopedia, dan lain-lain) dengan fitur aktif atau nonaktif koneksi.

j. Modul Manajemen Admin
   Admin dapat mengelola pengguna (lihat, edit, aktifkan atau nonaktifkan, hapus), mengelola artikel atau konten, mengelola paket langganan (termasuk pengaturan diskon upgrade), memantau seluruh langganan pengguna, serta memantau dan mengelola transaksi pembayaran (bisa melakukan pembatalan dan refund).


1.3 User Story

User story adalah pernyataan sederhana dalam sudut pandang pengguna yang mendeskripsikan fitur atau fungsi yang diinginkan dari sebuah sistem. Berikut adalah user story untuk aplikasi Bookify:

1. Sebagai pengguna UMKM, saya ingin mencatat setiap transaksi pemasukan dan pengeluaran dengan mudah, agar pembukuan usaha saya lebih rapi dan terorganisir.

2. Sebagai pengguna UMKM, saya ingin mengelola daftar produk beserta stoknya, agar saya dapat memantau ketersediaan barang dan mengetahui kapan harus melakukan restock.

3. Sebagai pengguna UMKM, saya ingin melihat ringkasan performa bisnis saya dalam bentuk grafik dan statistik, agar saya dapat mengambil keputusan bisnis dengan lebih baik.

4. Sebagai pengguna UMKM, saya ingin mengunduh laporan keuangan dalam bentuk PDF, agar saya dapat menyimpannya atau membagikannya kepada pihak lain seperti bank atau konsultan pajak.

5. Sebagai pengguna UMKM, saya ingin berdiskusi dengan pengguna lain melalui forum komunitas, agar saya dapat saling bertukar informasi dan pengalaman seputar pengelolaan usaha.

6. Sebagai pengguna UMKM, saya ingin memilih paket langganan yang sesuai dengan kebutuhan dan budget saya, baik bulanan maupun tahunan.

7. Sebagai pengguna, saya ingin mendapatkan diskon otomatis ketika melakukan upgrade dari paket dasar ke paket yang lebih tinggi, agar saya merasa dihargai sebagai pelanggan setia.

8. Sebagai pengguna, saya ingin melihat riwayat pembayaran langganan saya, agar saya dapat memantau transaksi yang pernah dilakukan.

9. Sebagai pengguna, saya ingin menambahkan beberapa item ke dalam keranjang sebelum checkout, agar saya dapat mengelola pembelian dengan lebih fleksibel.

10. Sebagai pengguna, saya ingin menghubungkan toko online saya di marketplace ke Bookify, agar saya dapat mengelola semua penjualan dari satu tempat.

11. Sebagai admin, saya ingin mengelola seluruh pengguna Bookify, termasuk mengaktifkan, menonaktifkan, mengedit, dan menghapus akun, agar ekosistem pengguna tetap terjaga kualitasnya.

12. Sebagai admin, saya ingin mengelola paket langganan yang ditawarkan, termasuk harga dan diskon upgrade, agar strategi penawaran dapat disesuaikan dengan kondisi bisnis.

13. Sebagai admin, saya ingin memantau seluruh langganan aktif pengguna dan melakukan pembatalan atau refund jika diperlukan, agar administrasi keuangan tetap terkontrol.

1.5 Use Case Specification

Use case specification adalah penjabaran detail dari setiap use case yang mencakup nama use case, aktor, deskripsi, prasyarat, alur utama, alur alternatif, dan kondisi akhir. Berikut adalah spesifikasi untuk use case-use case utama Bookify:

==================================================
Spesifikasi Use Case UC-01: Login ke Sistem
==================================================
Nama Use Case       : Login ke Sistem
Aktor               : Pengguna, Administrator
Deskripsi           : Pengguna atau admin memasukkan kredensial (email dan password) untuk masuk ke dalam sistem Bookify.
Prasyarat           : Pengguna belum terautentikasi dan memiliki akun yang sudah terdaftar di sistem.
Alur Utama          :
  1. Pengguna membuka halaman login.
  2. Sistem menampilkan form login dengan kolom email dan password.
  3. Pengguna mengisi email dan password, lalu menekan tombol Masuk.
  4. Sistem memvalidasi kredensial.
  5. Sistem mengarahkan pengguna ke dashboard sesuai rolenya (user ke Dashboard User, admin ke Dashboard Admin).
Kondisi Akhir       : Pengguna berhasil masuk ke sistem dan dapat mengakses fitur sesuai hak aksesnya.
Alur Alternatif     :
  - Jika email atau password salah, sistem menampilkan pesan error dan pengguna diminta mencoba kembali.

==================================================
Nama Use Case       : Mencatat Transaksi Pemasukan
Aktor               : Pengguna

  - Jika transaksi sudah berstatus Dibatalkan atau Direfund, sistem menolak aksi dan menampilkan pesan kesalahan.
